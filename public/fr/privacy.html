Politique de confidentialité de Mapica

Dernière mise à jour : 26 août 2026 · Mapica · mapica.app

La présente Politique de confidentialité explique comment Mapica collecte, utilise, conserve et partage les données personnelles lorsque vous utilisez l'application Mapica, mapica.app, les pages publiques des Local Creators et des parcours, ainsi que les services Mapica associés.

Mapica aide les voyageurs à recevoir des plans de voyage et des parcours personnalisés préparés par des Local Creators. Les billets, l'hébergement, la location de voitures et certains autres services de voyage peuvent être fournis par des partenaires indépendants. Une fois que vous quittez Mapica pour poursuivre vers le site ou le paiement d'un partenaire, la politique de confidentialité de ce partenaire s'applique également.

Qui nous sommes

Le responsable du traitement de vos données personnelles opère sous la marque Mapica.

  • Site. https://mapica.app
  • Vie privée. privacy@mapica.app
  • Assistance. support@mapica.app

Pour toute demande relative à vos données personnelles ou à vos droits en matière de vie privée, contactez privacy@mapica.app.

Informations que nous collectons

Les informations que nous traitons dépendent de la manière dont vous utilisez Mapica.

Compte et authentification

Nous pouvons traiter :

  • votre adresse e-mail ;
  • votre identifiant de compte Mapica ;
  • les identifiants reçus lorsque vous vous connectez avec Apple ou Google ;
  • votre nom ou nom d'affichage ;
  • la langue de l'interface ;
  • les informations d'authentification et de session.

Les mots de passe sont gérés via Supabase Auth et ne sont pas stockés en clair dans la base de profils Mapica.

Informations de profil

Vous pouvez choisir de fournir :

  • votre nom ;
  • une photo de profil ou un avatar ;
  • la ville et le pays ;
  • la date de naissance lorsque cela est nécessaire pour l'éligibilité liée à l'âge ou une fonctionnalité concernée ;
  • la langue ;
  • les préférences de notification ;
  • d'autres informations de profil facultatives.

Lorsqu'une date de naissance complète n'est pas nécessaire pour une fonctionnalité, Mapica s'efforce de ne pas l'utiliser au-delà de ce qui est nécessaire.

Informations relatives au voyage

Lorsque vous créez un voyage, nous pouvons traiter :

  • les destinations ;
  • les dates de voyage ;
  • le nombre et le type de voyageurs ;
  • si des enfants voyagent et leur tranche d'âge ;
  • les centres d'intérêt ;
  • le rythme préféré ;
  • le budget ;
  • les préférences d'hébergement ;
  • la disponibilité d'une voiture ;
  • les préférences de billets et de transport ;
  • les messages ou demandes particulières que vous choisissez de fournir ;
  • les informations d'itinéraire et de parcours ;
  • les lieux associés à votre voyage ;
  • les interactions avec votre voyage.

Veuillez ne pas inclure d'informations personnelles sensibles dans les champs de texte libre, sauf si cela est réellement nécessaire pour votre voyage.

Messages et contenus téléversés

Nous pouvons traiter :

  • les messages avec un Local Creator ;
  • les messages envoyés via le chat Mapica ;
  • les photos et images que vous choisissez de téléverser ;
  • les images de couverture de parcours ;
  • les parcours, lieux et descriptions que vous créez ;
  • les avis et autres contenus générés par les utilisateurs.

Candidatures Local

Si vous postulez pour devenir Local Creator, nous pouvons également traiter :

  • votre nom ;
  • le pays et la ville ;
  • les langues ;
  • vos informations « à propos » ;
  • les zones ou régions que vous connaissez ;
  • les catégories d'expertise ;
  • un mini-parcours d'exemple ;
  • le statut de la candidature ;
  • les communications relatives à votre candidature.

Les candidatures Local sont examinées par des membres autorisés de l'équipe Mapica. L'approbation ou le rejet d'une candidature Local n'est pas fondé exclusivement sur une décision automatisée.

Profils publics Local

Une fois qu'un Local est approuvé, certaines informations peuvent devenir publiquement disponibles, notamment :

  • le nom public ;
  • la photo de profil ;
  • la ville ou la région ;
  • les langues ;
  • les informations « à propos » ;
  • l'expertise ;
  • les parcours publiés ;
  • les notes ou indicateurs publics lorsque ces fonctionnalités sont activées.

Votre adresse e-mail et votre date de naissance ne sont pas affichées sur le profil public Local.

Localisation

Si vous donnez votre autorisation, Mapica peut traiter la localisation précise ou approximative de l'appareil afin de :

  • afficher votre position sur la carte ;
  • calculer des itinéraires ;
  • fournir une navigation à pied ;
  • afficher des lieux à proximité ;
  • fournir des fonctionnalités qui dépendent directement de votre localisation.

Mapica demande l'accès à la localisation via les contrôles d'autorisation du système d'exploitation. Vous pouvez refuser ou retirer l'autorisation de localisation dans les réglages de votre appareil. Certaines fonctionnalités liées à la carte peuvent être moins efficaces sans accès à la localisation.

Informations relatives à l'appareil et informations techniques

Nous pouvons traiter :

  • l'adresse IP ;
  • le type d'appareil ;
  • le système d'exploitation ;
  • la version de l'application ;
  • la langue de l'appareil ;
  • les identifiants techniques ;
  • le jeton d'enregistrement Firebase Cloud Messaging pour les notifications push ;
  • les informations d'erreur et de plantage ;
  • les journaux serveur ;
  • les informations de sécurité et de prévention des abus.

Paiements

Lorsque vous achetez un parcours Mapica ou un autre service vendu directement par Mapica, nous pouvons traiter :

  • l'identifiant de transaction ;
  • le montant ;
  • la devise ;
  • le statut du paiement ;
  • le produit acheté ;
  • les informations nécessaires à la comptabilité ou au traitement des litiges.

Les paiements sont traités par Stripe. Mapica ne stocke pas les numéros complets de cartes de paiement.

Stripe peut agir en tant que sous-traitant pour certaines activités de paiement et en tant que responsable du traitement indépendant pour certains traitements qu'il effectue à ses propres fins juridiques, réglementaires, de prévention de la fraude ou de service.

Origine des informations

La plupart des informations sont fournies directement par vous.

Nous pouvons également recevoir des informations limitées :

  • d'Apple ou de Google lorsque vous utilisez la connexion sociale ;
  • de Stripe concernant le statut du paiement ;
  • de votre appareil lorsque vous accordez des autorisations ;
  • du Local Creator impliqué dans votre voyage ;
  • de nos prestataires d'infrastructure et de sécurité ;
  • de sources publiquement disponibles lorsque cela est nécessaire pour une fonctionnalité dont vous avez été informé.

Pourquoi nous utilisons vos informations et nos bases juridiques

En vertu du RGPD, nous ne traitons les données personnelles que lorsque nous disposons d'une base juridique appropriée.

Exécution d'un contrat ou mesures précontractuelles

Nous traitons des informations lorsque cela est nécessaire pour :

  • créer et gérer votre compte ;
  • créer un voyage ;
  • envoyer une demande de voyage à un Local Creator ;
  • préparer et fournir un itinéraire ;
  • exploiter la marketplace Mapica ;
  • traiter un achat Mapica ;
  • fournir un service payant ;
  • assurer le support client.

Base juridique : article 6(1)(b) du RGPD.

Consentement

Nous pouvons nous fonder sur le consentement pour :

  • l'accès à la localisation précise lorsque le consentement est requis ;
  • les technologies d'analytique ou de suivi facultatives ;
  • les communications marketing lorsque le consentement est requis par la loi ;
  • les autorisations ou fonctionnalités facultatives de l'appareil.

Base juridique : article 6(1)(a) du RGPD.

Vous pouvez retirer votre consentement à tout moment. Le retrait n'affecte pas la licéité du traitement effectué avant le retrait.

Intérêts légitimes de Mapica

Nous pouvons traiter des informations limitées lorsque cela est nécessaire pour des intérêts légitimes tels que :

  • la protection des comptes ;
  • la prévention de la fraude et des abus ;
  • le maintien de la sécurité du service ;
  • les diagnostics techniques ;
  • l'amélioration de la fiabilité du produit ;
  • l'analytique produit pour comprendre l'usage des fonctionnalités et l'expérience utilisateur ;
  • la modération de la marketplace ;
  • l'examen des candidatures Local ;
  • la constatation, l'exercice ou la défense de droits en justice.

Base juridique : article 6(1)(f) du RGPD. Nous ne nous fondons pas sur cette base lorsque vos droits et intérêts prévalent sur les nôtres.

Obligations légales

Certaines informations relatives aux paiements, à la comptabilité, à la fiscalité ou aux litiges peuvent être traitées ou conservées lorsque cela est nécessaire pour respecter le droit applicable. Base juridique : article 6(1)(c) du RGPD.

Avec qui nous partageons les informations

Nous ne vendons pas vos données personnelles. Nous partageons des données personnelles uniquement avec les destinataires qui en ont besoin pour la finalité concernée. Les tiers avec lesquels nous partageons des données sont tenus d'assurer une protection des données des utilisateurs égale ou équivalente à celle énoncée dans la présente Politique de confidentialité.

Local Creators

Lorsque vous demandez un voyage personnalisé, le Local Creator assigné reçoit les informations raisonnablement nécessaires pour préparer votre voyage, ce qui peut inclure la destination, les dates, le groupe de voyageurs, les centres d'intérêt, le rythme, le budget, les préférences de voyage et votre message au Local. Nous nous efforçons de ne pas divulguer d'informations inutiles à l'exécution de la demande.

Supabase

Nous utilisons Supabase pour l'authentification, la base de données PostgreSQL, le stockage, le Realtime, les Edge Functions et l'infrastructure backend. Supabase traite les informations afin de fournir ces services à Mapica.

Stripe

Stripe fournit le traitement des paiements ainsi que des fonctionnalités associées de prévention de la fraude et de sécurité. Selon l'activité, Stripe peut agir en tant que sous-traitant ou en tant que responsable du traitement indépendant.

Google Maps Platform et Google Places

Mapica utilise Google Maps et Google Places pour les cartes, la recherche de lieux et les fonctionnalités associées. Lorsque ces services sont utilisés, Google peut recevoir des informations techniques, des termes de recherche, des adresses IP et des coordonnées de localisation conformément aux conditions de Google Maps Platform et à la politique de confidentialité de Google. Pour certains traitements, Mapica et Google agissent en tant que responsables du traitement indépendants des données personnelles concernées.

Firebase

Firebase peut être utilisé pour la diffusion des notifications push et des fonctionnalités techniques de l'application. Pour les notifications push, un jeton d'appareil ou d'enregistrement et d'autres informations techniques nécessaires à la diffusion de la notification peuvent être traités.

PostHog, Inc.

Mapica utilise PostHog comme service d'analytique produit afin de comprendre comment les utilisateurs interagissent avec l'application Mapica, mesurer l'usage des fonctionnalités, diagnostiquer des problèmes techniques et améliorer le produit. PostHog traite ces informations pour le compte de Mapica en tant que prestataire / sous-traitant.

Mapica a configuré l'hébergement PostHog Cloud UE (hôte d'ingestion eu.i.posthog.com). Selon les fonctionnalités activées dans Mapica, PostHog peut traiter des informations telles que :

  • les interactions dans l'application et les écrans consultés ;
  • des identifiants de session et techniques générés par le SDK d'analytique ;
  • des informations sur l'appareil et l'application (par exemple type d'appareil, système d'exploitation et version de l'app) ;
  • des événements de diagnostic et d'usage produit (par exemple étapes du parcours de paiement, sans données de carte) ;
  • un identifiant de compte Mapica pseudonyme après connexion, lorsque cela est nécessaire pour comprendre l'usage du produit entre sessions.

Mapica n'utilise pas Session Replay de PostHog dans la configuration actuelle de l'application. Mapica n'envoie pas à PostHog le contenu des messages de chat, les données de carte de paiement, les jetons d'authentification ni les mots de passe. Mapica n'utilise pas PostHog pour le suivi publicitaire cross-app ni pour constituer des profils publicitaires destinés à des tiers.

Les données d'événements d'analytique sont conservées selon la configuration du projet PostHog de Mapica et pas plus longtemps que nécessaire à l'amélioration du produit et au diagnostic. Vous pouvez demander la suppression des données d'analytique liées à votre compte via privacy@mapica.app ou en supprimant votre compte Mapica.

Vercel et Cloudflare

Mapica peut utiliser Vercel et, le cas échéant, Cloudflare pour le site web, le serverless, le réseau et l'infrastructure de sécurité. Ces prestataires peuvent traiter des requêtes techniques, des adresses IP et des journaux serveur dans le cadre de la fourniture de leurs services.

Connexion Apple et Google

Si vous choisissez Sign in with Apple ou Google Sign-In, le prestataire concerné traite les informations selon ses propres conditions de confidentialité. Mapica ne reçoit que les informations nécessaires pour créer ou authentifier votre compte Mapica conformément à la méthode de connexion que vous sélectionnez.

Partenaires voyage et affiliation

Mapica peut fournir des liens vers des prestataires indépendants de billets, trains et bus, attractions, hébergement, location de voitures et autres services de voyage. Cela peut inclure des prestataires tels qu'Omio, Tiqets, Viator, Expedia et DiscoverCars.

Lorsque vous suivez un lien d'affiliation ou un deep link, le partenaire peut recevoir des informations telles qu'un identifiant de parrainage ou d'affiliation, le produit sélectionné, la destination, les dates de voyage ou d'autres paramètres contextuels du lien, ainsi que des informations techniques associées au parrainage.

Après avoir quitté Mapica, le partenaire collecte de manière indépendante toute information que vous fournissez lors de la recherche ou du paiement et traite ces informations selon sa propre politique de confidentialité. Mapica ne traite pas les données de votre carte de paiement pour ces achats effectués auprès de partenaires indépendants.

Autorités et divulgations légales

Nous pouvons divulguer des informations lorsque la loi applicable l'exige, sur demande valide d'une autorité compétente, ou lorsque cela est raisonnablement nécessaire pour protéger Mapica, ses utilisateurs ou des droits légaux.

Transferts internationaux

Certains de nos prestataires opèrent à l'international, de sorte que des données personnelles peuvent être traitées en dehors de l'Espace économique européen.

Lorsque le RGPD exige des garanties supplémentaires pour de tels transferts, nous utilisons un ou plusieurs mécanismes licites, qui peuvent inclure :

  • les décisions d'adéquation de la Commission européenne ;
  • le Data Privacy Framework UE–États-Unis pour les organisations certifiées, le cas échéant ;
  • les clauses contractuelles types de la Commission européenne ;
  • d'autres mécanismes de transfert autorisés par le droit applicable en matière de protection des données.

Vous pouvez demander davantage d'informations sur les garanties utilisées pour les transferts internationaux en contactant privacy@mapica.app.

Cookies, SDK et technologies similaires

Notre site et notre application peuvent utiliser des mécanismes techniques de stockage ou d'accès nécessaires à des finalités telles que l'authentification, la sécurité, la mémorisation des préférences utilisateur, les deep links et la fourniture des fonctionnalités essentielles.

L'application mobile Mapica utilise le SDK PostHog pour l'analytique produit in-app, comme décrit ci-dessus. Il ne s'agit pas d'un cas d'usage de bannière cookies web ; le site marketing de Mapica n'intègre actuellement pas PostHog.

Lorsque Mapica utilise des technologies d'analytique, de publicité ou de suivi facultatives qui nécessitent un consentement en vertu du droit applicable, ces technologies ne doivent pas être activées avant l'obtention du consentement requis. Lorsque le consentement est requis, vous devez pouvoir le refuser ou le retirer aussi facilement que vous l'avez donné.

Une fois que vous visitez un partenaire de voyage indépendant, ses propres choix en matière de cookies et de suivi s'appliquent.

Notifications push

Si vous autorisez les notifications, Mapica peut envoyer :

  • des mises à jour de voyage ;
  • des messages relatifs à un Local ;
  • des mises à jour du statut d'une commande ou d'un parcours ;
  • des notifications de sécurité ;
  • d'autres notifications Mapica liées au service.

Vous pouvez désactiver les notifications push dans les réglages iOS. Les notifications marketing, si elles sont introduites, seront gérées séparément conformément aux exigences de consentement applicables.

Durée de conservation des informations

Nous ne conservons pas les données personnelles plus longtemps que nécessaire au regard de la finalité pour laquelle elles ont été collectées.

Sauf si une durée plus longue est exigée par la loi ou nécessaire pour un litige, nous appliquons les durées de conservation générales suivantes :

  • Compte et profil. Tant que votre compte reste actif et jusqu'à la finalisation de la suppression du compte.
  • Voyages, messages privés et préférences. Tant que cela est nécessaire pour le compte ou le service ; après la suppression du compte, ces données sont généralement supprimées ou anonymisées des systèmes actifs sous 30 jours.
  • Sauvegardes. Les informations supprimées peuvent rester dans les systèmes de sauvegarde jusqu'à 90 jours avant rotation ou suppression des sauvegardes.
  • Candidatures Local. Les candidatures rejetées ou retirées sont généralement conservées au plus 12 mois, sauf si une conservation plus longue est nécessaire pour un litige ou la prévention des abus.
  • Jetons push. Jusqu'à ce que l'appareil ne soit plus enregistré, que les notifications soient désactivées, que le compte soit supprimé ou que le jeton devienne invalide.
  • Journaux de diagnostic et de sécurité. Généralement pas plus de 12 mois, sauf si une conservation plus longue est nécessaire pour enquêter sur un incident de sécurité.
  • Demandes relatives à la vie privée et au support. Les dossiers pertinents peuvent être conservés jusqu'à trois ans après la clôture de la demande lorsque cela est nécessaire pour démontrer la conformité ou protéger des droits légaux.
  • Dossiers de paiement et de comptabilité. Pour la durée exigée par le droit comptable et fiscal applicable. Lorsque les exigences françaises de conservation comptable s'appliquent, certains dossiers comptables peuvent être conservés jusqu'à 10 ans.

À l'expiration de la période concernée, les informations sont supprimées, anonymisées ou placées dans un stockage d'archives restreint lorsque la conservation continue est légalement requise.

Suppression du compte

Si vous créez un compte Mapica, vous pouvez initier la suppression de votre compte directement dans l'application :

Profil → Compte → Supprimer le compte

Vous pouvez également contacter privacy@mapica.app pour toute question relative à la suppression.

La suppression du compte inclut la suppression ou l'anonymisation des informations personnelles associées, à l'exception des informations que nous sommes tenus ou autorisés à conserver à des fins telles que :

  • les obligations comptables et fiscales ;
  • la prévention de la fraude ;
  • le respect de la loi ;
  • le règlement des litiges ;
  • la constatation, l'exercice ou la défense de droits en justice.

Le contenu public généré par l'utilisateur associé à un compte supprimé sera supprimé ou anonymisé, sauf s'il existe une raison légitime de le conserver.

Vos droits en matière de vie privée

Lorsque le RGPD ou une législation similaire s'applique, vous pouvez avoir le droit :

  • de savoir si nous traitons vos données personnelles ;
  • d'y accéder et d'en obtenir une copie ;
  • de corriger des informations inexactes ;
  • de demander la suppression ;
  • de restreindre le traitement ;
  • d'obtenir certaines informations dans un format portable ;
  • de vous opposer au traitement fondé sur les intérêts légitimes ;
  • de retirer votre consentement ;
  • de vous opposer au marketing direct ;
  • de ne pas faire l'objet de certaines décisions fondées exclusivement sur un traitement automatisé.

Pour exercer vos droits, contactez privacy@mapica.app. Nous pouvons demander des informations raisonnables pour vérifier votre identité.

Nous répondrons sans retard indu et normalement dans un délai d'un mois à compter de la réception de votre demande. Lorsque la loi le permet, ce délai peut être prolongé.

Vous avez également le droit d'introduire une réclamation auprès de l'autorité de contrôle compétente en matière de protection des données, notamment dans le pays de l'EEE de votre résidence habituelle, de votre lieu de travail ou du lieu de la violation alléguée.

Systèmes automatisés

Mapica peut utiliser des systèmes automatisés pour aider aux recommandations de voyage, à l'organisation d'itinéraires, à la sélection de contenus, à l'amélioration du service et à la modération technique.

Mapica n'utilise pas de décisions fondées exclusivement sur un traitement automatisé produisant des effets juridiques ou des effets similaires significatifs sur les utilisateurs sans base juridique appropriée et garanties requises. Les candidatures Local font l'objet d'un examen humain.

Si Mapica commence à envoyer des messages ou d'autres données personnelles à un prestataire d'IA tiers distinct, la présente Politique de confidentialité et les informations pertinentes dans l'application devront être mises à jour avant le début de ce traitement.

Enfants

Mapica n'est pas destiné à une utilisation indépendante par des enfants de moins de 16 ans. Une personne de moins de 16 ans ne doit pas créer son propre compte Mapica.

Un titulaire de compte adulte peut fournir des informations limitées sur les enfants voyageant avec lui, telles que le nombre d'enfants ou la tranche d'âge, lorsque cela est nécessaire pour préparer un voyage adapté. Veuillez ne pas fournir d'informations sensibles inutiles concernant un enfant.

Si nous apprenons qu'un enfant a créé un compte en violation de nos exigences d'âge, nous prendrons des mesures raisonnables pour supprimer le compte et les informations associées.

Sécurité

Nous utilisons des mesures techniques et organisationnelles destinées à protéger les informations personnelles contre l'accès non autorisé, l'utilisation illicite, l'altération, la perte accidentelle, la divulgation et la destruction. Toutefois, aucun service internet ne peut garantir une sécurité absolue.

Modifications de la présente Politique

Nous pouvons mettre à jour la présente Politique de confidentialité de temps à autre. La date de « Dernière mise à jour » en haut de cette page indique quand la Politique a été modifiée le plus récemment.

Si une modification affecte de manière substantielle l'utilisation des données personnelles, nous fournirons un avis supplémentaire lorsque la loi l'exige ou lorsque cela est approprié au regard de la modification.
